## 다시 렌더링

`../jev-motion/README.md`와 같은 방식입니다. `fonts/`에 같은 폰트 5종을 두고:

```bash
NODE_PATH=$(npm root -g) node render.js stills 4.8,12.9,22.0   # 원하는 시점 스틸
NODE_PATH=$(npm root -g) node render.js video                  # decision-ai-war-30s.mp4
```
